Agent Skill · 给第一次做真实项目的学生

BuildBuddy

从“不知道做什么”，到一个能运行、能验证、也能由你讲清楚的第一版。你可以只有一个模糊方向，甚至暂时没有点子。

我没方向，先看怎么开始 查看 GitHub 仓库 怎么安装

如果你卡在第一步

  • 会一点 Python、前端或数据分析，却还没独立完成过一个真实项目？
  • 想做可信的作品集，或验证第一笔软件收入，却不知道该从什么真实问题开始？
  • 跟过教程、做过作业，但不知道怎样找到首位用户、缩小范围和判断“真的做完了”？

BuildBuddy 把编程 Agent 变成自主执行的“建设者 + 教练”：先从你接触得到的人和问题里选择方向，再收缩范围、实现、验证，并且每个阶段只讲一个有用概念。

从会一点技术，到自己的第一版

项目最初关注的是许多 985/211 学生也会遇到的落差：学过不少，却缺从知识到真实用户的路径；学校标签不是门槛。BuildBuddy 不承诺写完网页就能赚钱，而是把技术可用、有人使用、重复使用和愿意付费分开验证。

你我是大二学生，会一点 Python 和前端，但只做过课程作业。看到别人做网页赚钱，我不知道从哪开始。先从同学、社团和实验室问题里给我不超过三个方向，推荐一个零预算选择。
BuildBuddy先不选框架，也不急着部署。我会确认你的主要目标、这周能接触的人和可观察的重复问题；然后给出跨 Web、CLI 或数据工具的候选、一个推荐默认项，以及最便宜的开发前验证动作。方向有证据后，再开始做首位真实用户能试的版本。

它怎么工作

按产品选路线可选择 Web、后端/API、CLI/自动化、数据/AI、库/SDK、移动/桌面或混合路线。已有项目优先沿用原技术栈和约定。
先验证再声称每项结论都对应新鲜的静态、逻辑、集成、界面或发布证据。单元测试不能冒充没跑过的浏览器、软件包、模型或设备流程。
做完才讲每个阶段一段 4 行回顾：做了什么、为什么这样做、你学到了什么、验证了什么。输出稀疏、没有进度卡，讲完自动继续。
只在真实边界停缺少授权、密钥或付费资源，涉及敏感生产数据、难以撤销的选择，或已经没有不同且安全的诊断路径。
诚实地交付未经授权的外部动作先询问，再验证真正的交付入口。公网网址、软件包、模型产物或 App 构建只有实际检查过才会声称完成。
保护你的工作绝不 reset 或覆盖你未提交的改动，绝不 force-push；只回滚它自己的修改。
适配你的环境有终端就自己跑；纯聊天里就把文件和精确命令交给你——绝不声称跑过它跑不了的东西。
帮你找到方向不知道写啥？一套问题猎取法 + 三问指路器，把“我不知道”变成一个可以交给首位用户试的小项目。

看一段工作流示范

你做一个 macOS 和 Linux 都能用的 CLI，按 EXIF 日期重命名照片。默认只预演、处理重名，而且绝不能拿我的唯一原件测试。
BuildBuddy路线：新项目 · CLI/自动化 · 破坏性操作风险层。结果：先输出确定的重命名计划，只有明确确认后才真正执行。非目标：修改照片内容，或拿原件做测试。

[切片 1：读取复制出来的样例文件，输出稳定的预演计划。]

证据：缺日期与重名的单元测试，加上临时目录里的真实子进程运行。

[切片 2：增加确认执行、幂等性、中断恢复、打包和干净安装冒烟测试。]
收工只对实际运行过的平台作出结论：预演不会改文件；确认后能处理重名；第二次运行不再产生变化；干净安装后命令可用。没有测试的平台会明确写成限制，不会暗示已支持。

快捷指令

  • /pause 停下自动流程，等我
  • /test 运行当前快速证据集
  • /test full 运行完整验收证据集
  • /ideas 寻找并选择产品方向
  • /explain 用白话解释当前切片
  • /review 检查范围、正确性、可维护性和证据
  • /deploy 按交付选择与授权边界推进
  • /retrospective 复盘我学到了什么

安装

Codex —— 一条命令

下载仓库后运行：

bash install.sh

或把完整的 buildbuddy 文件夹复制到 ~/.codex/skills/。引用资料、模板、评测和校验脚本都是 skill 的一部分；只复制 SKILL.md 并不完整。文件夹名必须是 buildbuddy。

DeepSeek Harness

把 buildbuddy 文件夹放进项目里的 .dsh/skills 或 .agents/skills 目录，或者放进 ~/.dsh/skills。

Claude Code / Cursor

把文件夹放进对应工具的 skills 目录（例如 ~/.claude/skills/，或 Cursor 项目里的 .agents/skills）。

使用

开新对话，说一个有一定规模的结果，比如“做一个带预演和恢复能力的安全照片重命名 CLI。”如果 skill 没有自动加载，就说“使用 buildbuddy 这个 skill。”
